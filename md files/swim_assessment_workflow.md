# Swim Assessment Workflow

## Overview
This document outlines the decision tree for placing students into the correct swim level. 

Before evaluating age-specific skill questions, the assessment asks if the student needs a modified or adaptive lesson. If so, they are placed directly into the **Dolphin** program with options for a **Private** or **Semi-Private** lesson. Otherwise, the workflow proceeds to their age group's sequential skill questions.

---

## 1. Initial Screening (All Age Groups)

**Q0: Does the swimmer need a modified or adaptive lesson?**
- If **YES** -> **Result: Dolphin** (Requests Private Lesson or Semi-Private Lesson).
- If **NO** -> Proceed to their age group workflow below.

---

## 2. Age Categorization & Skill Workflows

### Child (3–24 Months) Workflow
**Q1: First time in Swim lessons?**
- If **NO**, proceed to Q2.
- If **YES**, proceed to Q2.

**Q2: Are they comfortable in the water and can they fully submerge their head?**
- If **NO** -> **Result: Tadpole 6:1**
- If **YES** -> **Result: Swimboree 4:1**

*(Note: Separation from parent/caregiver is not evaluated for this age group).*

---

### Child (24–36 Months) Workflow
**Q1: First time in Swim lessons?**
- If **YES** -> **Result: Tadpole 6:1**
- If **NO**, proceed to Q2.

**Q2: Are they comfortable in the water and can they fully submerge their head?**
- If **NO** -> **Result: Tadpole 6:1**
- If **YES**, proceed to Q3.

**Q3: Can they separate from the parent and caregiver and work directly with our instructors?**
- If **NO** -> **Result: Swimboree 4:1**
- If **YES**, proceed to Q4.

**Q4: Can they sit on the edge of the pool and wait independently for their turn?**
- If **NO** -> **Result: Swimboree 4:1**
- If **YES** -> **Result: Seahorse 4:1**

---

### Child (3–12 Years) Workflow
**Q1: First time in Swim lessons?**
- If **YES** -> **Result: Starfish 4:1**
- If **NO**, proceed to Q2.

**Q2: Are they comfortable in the water and fully able to submerge their head?**
- If **NO** -> **Result: Starfish 4:1**
- If **YES**, proceed to Q3.

**Q3: Are they able to float on their back unassisted without a life vest?**
- If **NO** -> **Result: Starfish 4:1**
- If **YES**, proceed to Q4.

**Q4: Are they able to jump in, roll over and float without assistance?**
- If **NO** -> **Result: Minnow 4:1**
- If **YES**, proceed to Q5.

**Q5: Can they swim freestyle and backstroke with their arms out of the water?**
- If **NO** -> **Result: Turtle 1 4:1**
- If **YES** -> **Result: Turtle 2 6:1**

---

### Young Adult (13–17) Workflow
**Q1: First time in Swim lessons?**
- If **YES** -> **Result: Young Adult 1**
- If **NO**, proceed to Q2.

**Q2: Are they comfortable in the water and can they float on their back by themselves?**
- If **NO** -> **Result: Young Adult 1**
- If **YES**, proceed to Q3.

**Q3: Can they put their face in the water and hold their breath?**
- If **NO** -> **Result: Young Adult 1**
- If **YES**, proceed to Q4.

**Q4: Can they swim 10 yards of freestyle and backstroke with their face in the water and utilizing a side breath?**
- If **NO** -> **Result: Young Adult 2**
- If **YES** -> **Result: Young Adult 3**

---

### Adult (18+) Workflow
**Q1: Have you had swim lessons before?**
- If **NO** -> **Result: Adult 1**
- If **YES**, proceed to Q2.

**Q2: Can you float on your back by yourself for 20 seconds?**
- If **NO** -> **Result: Adult 1**
- If **YES**, proceed to Q3.

**Q3: Can you tread water for 1 minute?**
- If **NO** -> **Result: Adult 2**
- If **YES**, proceed to Q4.

**Q4: Can you swim the freestyle and backstroke with arms out of the water?**
- If **NO** -> **Result: Adult 2**
- If **YES** -> **Result: Adult 3**
